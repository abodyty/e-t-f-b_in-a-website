# E.T.F.B. – Roblox-Inspired Multiplayer Game

**Created by Abdulwahab Musaad (10 years old)**

E.T.F.B. is a Roblox-inspired game recreated as a web-based experience using HTML. The project brings a multiplayer gaming experience directly to the browser, allowing players to join, interact, and communicate with each other.

### Features
- **Multiplayer Support:** Real-time multiplayer functionality powered by Supabase.
- **User Identity:** Uses Supabase to remember players and maintain their identity.
- **In-Game Chat:** Players can communicate through an integrated chat system powered by Supabase.
- **3D Models:** Game models sourced from [Sketchfab](https://sketchfab.com/).
- **AI-Assisted Development:** Claude was used as an AI development assistant during the project.

### Technologies & Tools
- HTML
- Supabase (Database, Multiplayer & Chat)
- Claude AI
- Sketchfab (3D Models)
